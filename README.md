# F1 Race Intelligence

A Formula 1 data science project focused on qualifying analysis and race strategy simulation.

## Overview

This project aims to build two simulation tools:

### Qualifying Cutoff Simulator

A statistical simulator to estimate the minimum lap time required to progress through:

- Q1
- Q2
- Q3

using historical qualifying data and probability models.


### Race Strategy Simulator

A Monte Carlo simulation framework to model:

- tyre degradation
- pit stop strategies
- traffic
- safety cars
- weather conditions
- race outcomes


## Objectives

The goal is to combine:

- Data engineering
- Statistical modelling
- Simulation
- Data visualization
- Python software development
